# Nearby places, per city

One file per city, in the format the staff screen accepts (Admin, Nearby places): `Kind | Name | latitude, longitude`.
To load a city on a fresh database, paste its file into that screen.

Fetched on 19 November 2026.

- Metro stations and airports: OpenStreetMap, stations tagged as in service. Stations tagged as under construction
  or proposed were left out. Lines that opened recently are worth checking by hand.
- Main railway stations and business districts: a hand-picked list, placed with OpenStreetMap's search.
- Schools, hospitals and malls are not included; add them from the staff screen.
